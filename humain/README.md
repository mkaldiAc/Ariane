# ARIANE — espace humain

Ce dossier regroupe les ressources destinées à la compréhension, à la gouvernance et au travail humain autour d’ARIANE.

Il peut contenir des fichiers Markdown, Word, Excel ou tout autre support de travail.

## Organisation

- `guide-fonctionnel.md` : vision fonctionnelle consolidée du processus ARIANE ;
- `referentiel/` : documentation lisible par un humain sur la structure, les attributs et les relations ;
- `decisions/` : mémoire des arbitrages validés ;
- `historique/` : ressources de migration et anciennes nomenclatures ;
- `livrables/` : emplacement des fichiers de travail Excel, Word, etc.

## Règle de priorité

Pour l’exécution d’une captation, les fichiers de `../ia/` constituent le paquet destiné à l’IA et prévalent comme contrat opérationnel.

Les documents de ce dossier expliquent les choix et facilitent la gouvernance, mais ne sont pas nécessaires au runtime IA.
